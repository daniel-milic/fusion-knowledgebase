# Platform Documentation Skills

Skills for capturing and maintaining knowledge about enterprise platforms.

## Example Skills
- Document a platform page or wizard (purpose, key fields, validations, downstream systems)
- Describe integration paths (Experience Layer → Boomi → Sonata, etc.)
- Map user journeys and business flows across platforms
- Record data dependencies and timing expectations for a given page or API
- Identify which Fusion scenarios / tasks currently cover a platform area

Outputs from these skills live primarily under `platforms/`.
