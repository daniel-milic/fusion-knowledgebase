# Knowledge Base Maintenance Skills

Skills for keeping this repository accurate and useful as a self-documenting harness.

## Example Skills
- Create or update a platform page/API document from gathered information
- Ensure cross-links between platforms, Fusion scenarios, and scripts stay consistent
- Propose structure improvements as the number of documented pages grows
- Summarise current automation coverage for a given domain or platform
- Generate index updates (READMEs) when new documents are added

These skills support the ongoing growth of the knowledge base itself.
