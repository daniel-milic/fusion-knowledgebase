# Skills

Reusable AI skills for working with this knowledge base and the related `fusion-scripts` repository.

Skills are focused on two main areas:
1. Documenting knowledge in a superannuation domain context
2. Understanding and evolving Fusion-based test automation (scenarios, tasks, datasets, and the Python scripts they drive)

## Categories

- [superannuation/](superannuation/) — Domain knowledge, terminology, processes, and platform concepts
- [platforms/](platforms/) — Documenting platforms, pages, wizards, APIs, and integrations
- [fusion/](fusion/) — Working with Fusion scenarios, tasks, datasets, and MongoDB structure
- [automation/](automation/) — Writing, healing, and maintaining test automation scripts that consume Fusion datasets
- [knowledge-base/](knowledge-base/) — Maintaining and extending this knowledge base itself

See each category README for the intended skills.
