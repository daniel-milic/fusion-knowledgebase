# Layout Rules

- Top level holds INDEX, README, PLATFORMS and domain folders only.
- Domain folders mirror `fusion-scripts/regression/<domain>/`.
- Platform folders mirror `fusion-scripts/regression/<domain>/<platform>/`.
- One concern per file. Create a file only when it holds real content.
- Every platform README uses the same headings (see templates).
- Every file must be linked from INDEX or from its folder README.
