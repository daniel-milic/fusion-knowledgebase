# Fusion Automation Skills

Skills focused on the Fusion test automation platform and its relationship to the Python scripts.

## Example Skills
- Retrieve and summarise scenarios and tasks, including the data each task holds
- Explain how a Fusion task maps to one or more Python scripts in the `fusion-scripts` repository
- Document the structure of Fusion MongoDB collections relevant to scenarios and tasks
- Identify gaps in coverage by comparing platform functionality to existing scenarios/tasks
- Prepare structured extracts that Copilot can use when updating automation scripts

These skills rely on the retrieval scripts in `management/scripts/fusion/`.
