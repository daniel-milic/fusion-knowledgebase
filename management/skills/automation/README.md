# Automation Script Skills

Skills that help GitHub Copilot maintain and evolve the `fusion-scripts` repository.

## Example Skills
- Generate a new Python script that follows the custom framework patterns and reads its Fusion task data
- Heal an existing script based on a failed execution or changed platform behaviour
- Align script parameters with the data fields defined in a Fusion task
- Add appropriate assertions and evidence capture consistent with existing patterns
- Document the link between a script, its Fusion task, and the platform page/API it exercises

These skills assume access to both this knowledge base and the `fusion-scripts` codebase.
