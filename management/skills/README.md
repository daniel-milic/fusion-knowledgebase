# Skills

Reusable AI skills for this knowledge base and the `fusion-scripts` repo. This is the planned list; split a skill into its own folder only when it is written.

## Superannuation domain
- Explain concepts and map business processes to platforms
- Identify data entities and their relationships
- Document timing and sequencing constraints
- Flag regulatory considerations for test data and scenarios

## Platform documentation
- Document a page, wizard or API from `management/templates/`
- Describe integration paths (Experience Layer → Boomi → Sonata)
- Record data dependencies and timings

## Fusion
- Summarise scenarios and tasks (uses `management/scripts/fusion/`)
- Map a task to its script in `fusion-scripts`
- Find coverage gaps between platform functionality and scenarios

## Automation
- Generate a script that follows the framework patterns and reads its task data
- Heal a script after a failed run or changed platform behaviour
- Record the link between script, task and platform page

## Knowledge base upkeep
- Create or update docs from gathered information
- Keep indexes and links consistent
- Enforce the rules in `management/layout.md`
