# User Interactions

How people use Fusion day to day.

- Creating a test scenario
- Defining a task (including its test data)
- Creating a test run: a selection of scenarios and their tasks (with datasets). Each selected scenario gets a `run_status` document, and each execution gets an id such as `5X12` ([run-status/test-runs.md](run-status/test-runs.md))
- Managing test runs (status, re-runs, healing)
- Baselining checkpoints: deciding whether a value is a pass or a fail
- Reviewing Alerts: Fusion web lists every checkpoint in `ALERT` status for a pass or fail decision
