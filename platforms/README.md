# Platforms

Detailed documentation for each platform (pages, wizards, APIs, flows, datasets).

## Structure
- `digital/` — Member-facing platforms
- `advice-admin/` — Registry, CRM, advice, letters
- `enterprise-services/` — Boomi and shared services

Each platform folder contains a `README.md` (overview + index) and subfolders such as `pages/` or `apis/` for individual focused documents.
