# Sonata (domain)

## Purpose
The admin domain. Sonata is the central registry (a Bravura product) for super members, employers, their accounts, and insurance. All platforms connect to it.

## Users
Internal

## Platforms in this domain
In `fusion-scripts/regression/sonata/`, seen so far in task `process` paths (create a folder here when a platform needs detail):
- `sbs` — Sonata APIs and the microsite register (`api-service`, `register-microsite`)
- `insurance` — e.g. `add-insurance`, `underwriting`, `issue-insurance`, `insurance-review`, `claim-notification`, `decision-maintenance`
- `orchestrator` — e.g. `claims-workspace`, `manage-claim-task-card`
- `employer-services` — e.g. `client-enquiry`, `account-enquiry`
- `system` — e.g. `reference-data`
